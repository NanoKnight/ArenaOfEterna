
# Arena of Eterna

Arena of Eterna is a Top-Down Hack and slash  developed with Unreal Engine 5 using both C++ and Blueprints. The project focuses on creating responsive combat mechanics, AI behaviors, inventory management, quests, and player progression.

---

## Features

### Combat System
- Light attack combo system
- Charged attacks
- Parry system
- Blocking with shield
- Dodge roll
- Motion Warping
- Lock-on targeting
- Hit reactions
- Enemy stagger
- Slow-motion effect on successful parry

### AI
- AI perception
- Combat Director system
- Dynamic attacker switching
- Patrol and chase behavior
- Attack range management
- Enemy spawners
- Wave system

### Character Progression
- Experience system
- Level system
- Stats progression

### Inventory
- Inventory system
- Equipment system
- Weapon system
- Shield system
- Consumable items

### Quest System
- DataTable-driven quests
- Quest tracker UI
- Quest completion rewards

### Save System
- Save & Load
- Enemy persistence
- Player progression saving

### UI
- Health, stamina and XP bars
- Inventory UI
- Quest UI
- Equipment UI
